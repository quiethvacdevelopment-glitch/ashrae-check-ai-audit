# ASHRAE Check AI Audit

This contains everything you need to run your app locally and deploy it.

**Live App (Vercel):** [https://ashrae-check-ai-audit.vercel.app](https://ashrae-check-ai-audit.vercel.app)
**View in AI Studio:** [https://ai.studio/apps/c1305550-029c-4d32-a2ed-0ba5be57329c](https://ai.studio/apps/c1305550-029c-4d32-a2ed-0ba5be57329c)

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
